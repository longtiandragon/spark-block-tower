# 项目状态与复现范围

本项目完成了一轮人工辅助三层搭建：操作员送料并确认每层支撑，最终画面及间隔五秒的画面显示塔体站立。当前自动方案增加三个固定料位独立标定、20 mm试提、多帧顶面随动、目标变化及源料位空置检查。自动整轮仍需现场验收，不能从软件通过推导实物成功率。

已有参数证据：20个课程平面标定点，X/Y拟合RMSE约0.98/1.82 mm。该指标属于样本拟合，不是独立工作区定位精度。三层支撑实测参考Z为-41.26、56.87、153.81 mm，单位是机械臂末端坐标，不是积木物理高度。

已完成的软件检查与复现方法见README。源码包含历史兼容分支，实际选择的运行入口和依赖必须与所讨论功能一致。
